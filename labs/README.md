# Labs

Use this folder for optional lab material, practice exercises, or small scaffolds that students can complete outside the main in-class examples.

Suggested structure:

```text
labs/<year>/<lab-name>/
```

Each lab should include its own README with goals, instructions, and expected deliverables.

## Available labs

- [Lab 4 — Pipelining and Performance (2026)](2026/lab-4-pipelining/): five RV32I starter programs for the single-cycle and five-stage processors in Ripes. Students create their submission in `labs/2026/lab-4/` in their own fork.
